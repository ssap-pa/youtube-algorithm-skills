## 1. 소재 고르기 — "모두 아는 것 × 아직 아무도 정리 안 한 것"
100만+ 영상의 소재는 거의 모두 이 곱셈이었다(우승은 다 봤지만 엄마 이야기는 모름 / 셔플은 다 알지만 사라진 이유는 모름 / 다낭 뉴스는 봤지만 실제 가격은 모름 / 본방은 봤지만 라커룸은 모름).

| 축 | 질문 | 예 |
|---|---|---|
| ① 모두 아는 것 | 이 단어(현상·사람·사건)를 시청자 열에 일곱이 이미 아는가? | 셔플 댄스, 한국시리즈 우승, 다낭, 미스터비스트 |
| ② 빈칸 | 많은 사람이 궁금했지만 답을 못 본 질문이 있는가? | 왜 갑자기 사라졌나, 진짜 싼가, 그 선수는 누구인가 |
| ③ 때 | 화제가 된 지 **2~3일 안**인가(우승 3일 뒤·선거 2일 뒤·공개 주·컴백 주)? 아니면 시간이 지나도 궁금한 것(향수)인가? | |

기획 장치 — 하나 이상 결합(39개에서 실제로 쓰인 것): 시의성 · 호기심 빈칸 · 대비·지위 역전(시키던 미스터비스트가 당함, 경찰이 용의자) · 인물 결합(유명인 × 낯선 상황) · 금지·비밀(미방분·소년원·못 가는 곳) · 극한·규모(폭우·2+1 거실·400kg) · 가족 감정 · 검증(뉴스 주장을 내가 직접 재 봄) · 약속 회수(지난 영상에서 한 약속).

**[내 채널]** ①은 내 분야에서 이미 퍼진 사례·도구·뉴스·인물, ②는 내 시청자가 진짜 궁금한 질문("그래서 실제로 되나·얼마 드나·얼마 버나"), ③은 발표·화제 2~3일 안. 1인 채널에 가장 잘 맞는 장치는 **검증**(다낭형: 화제 주장 → 내가 직접 해 본 실측 숫자 → 판정)과 **사라진/뜬 이유**(셔플형)다. '모두 아는 것'이 없는 소재(처음 듣는 제품 소개)는 후킹이 약하다 — 아는 이름에 붙인다.

## 2. 로그라인 한 줄 + 단일 질문
- 로그라인: **[누가] [무엇을] — [왜 지금 / 왜 이 사람이 보여 줘야 하나]**. 한 줄이 안 나오면 기획이 아직 아니다.
- 단일 질문: 영상 전체가 갚을 질문 **하나**(제목·썸네일·오프닝이 모두 이 질문을 가리킨다). 포장은 한 장면·한 감정에 몰고(20분 중 3분짜리 개인기, '시장에 간 이유' 하나), 영상은 그 하나를 끝까지 미뤄 끌고 간다.
- 공유될 한 줄: 시청자가 댓글에 그대로 옮길 **구체 숫자·말·판정 한 줄**을 미리 정한다("콜라 1700원", "뱉은 말을 지켰네", "안 합니다"). 논쟁이 붙을 판정이면 더 좋다.

## 3. 패키징 먼저 (구성 전에)
**제목과 썸네일은 역할을 나눈다** — 같은 말 반복은 소수였다.
- 제목 = 사람·원인·질문(+검색어). 썸네일 = 결과 장면·얼굴 반응·**실제 한마디**·근거 화면(헤드라인·글 캡처·실측 화면).

제목 문형(39개에서 실제 성과가 큰 순):
1. **사람의 고생 숫자 + 쉼표 + 반전 문장 + 두 칸 띄고 검색어 꼬리표** — "하루 14시간 미용실에서 세 아들 키운 엄마, 처음 나온 외국이 대구였다  페덱 삼성 우승"(구독 대비 1,655배)
2. **[모두 아는 현상]을 만든 이들이 갑자기 사라진/뜬 이유** — 고유명사 대신 현상으로 부르고, 이름은 썸네일에(58배)
3. **유행 밈·통념 인용 + 물음표 + 현실** — "경기도 다낭시는 옛말? 외면받는 동남아 현실!"(8.5배)
4. 권위자도 ~했던 N가지 / A vs B 어디가 더 ~? / '~하면 생기는 일' / 왜 ~걸까?(뉴스 48시간 안)
5. 시리즈·연재: 제목 = 시리즈명·회차, 썸네일이 이번 회 사건 하나를 전부 맡는다(팬덤이 있을 때만).

썸네일: 4~16자 2줄(흰 + 강조색 하나) 또는 0~1줄(얼굴·장면이 다 말할 때). 감정이 보이는 얼굴, 결과 장면.

**지키는 선**: 썸네일 따옴표는 **실제로 한 말만**(분석한 39개 중 5개가 하지 않은 말을 인용처럼 썼다 — 따라 하지 않는다). 숫자 단위를 바꾸지 않는다('2,800만 회' → '2800만명' 같은 것). **[내 채널]** 제목에 답(결과)을 넣을지, 누가 최종 확정하는지는 CHANNEL.md 규칙을 따른다(궁금증이 무기인 영상은 답을 숨기는 편이 맞다).

## 4. 구성 뼈대 고르기 (5종)
| 뼈대 | 흐름 | 약속 회수 위치 | 실제 사례 |
|---|---|---|---|
| **A. 콜드 오픈 플래시백** | 날짜·장소·숫자 위기 장면(결과 숨김) → "○○가 하나 더 있었습니다" 질문 → 과거로 → 1분마다 사건 → **2/3 지점에서 오프닝 장면 회수** → 클라이맥스 → 처음 장면으로 돌아가 의미를 바꾸는 수미상관 | 2/3 + 마지막 문장 | 페덱(9분, 1,655배) |
| **B. 흥망 곡선** | 집단 기억 소환 → 20초마다 반전 사실로 상승 → **절반에서 "바로 그 정점에서" 전환** → 하강(갈등·배신·숫자) → 마지막에 제목의 현상 회수 | 정확히 절반 | 셔플(16분, 58배) |
| **C. 실측 판정 뒤집기** | 화제 주장(뉴스 화면) → 첫 실측 숫자 + 화자 자격 → **3~4분마다 숫자 하나씩**, 판정을 뒤집으며 → 맨 끝에 최종 판정 + 다음 편 | 맨 끝 | 다낭(26분, 8.5배) |
| **D. 과정 완성** | 목표 선언("방 세 개를 만들어 보려고요") → 한 단계씩 완성 + 위기(물 고임·비) → 첫 보상 → 밤·아침 대비 → 완성 | 단계마다 + 끝 | FISH13(1,631만), RYUCAMP |
| **E. 해설 요약** | 결과 숫자 먼저 → 통념 뒤집기("엔화가 전부가 아니다") → 30~40초마다 새 숫자·반문 → 개별 사건을 구조로 넓힘 → 열린 질문 | 진짜 원인은 뒤 | 크랩(7분), 스브스뉴스(4분) |

**[내 채널]** 실측·실제 화면이 있으면 **C(검증)**, 인물 사례는 **A(플래시백)**, 이미 퍼졌다 꺾인 사업·제품·유행은 **B(흥망)**, 직접 만드는 과정은 **D**. E는 짧은 시의성 영상용. 편집을 클립 단위로 나눈다면 클립 경계를 뼈대의 전환점(절반·2/3)에 맞춘다.

## 5. 오프닝 0~60초
1. **인사·채널 소개로 시작하지 않는다**(39개 중 인사로 시작한 건 고정 팬층 시리즈 4개뿐). 첫 문장 = 본편에서 가장 센 사실·장면·숫자.
2. 0~20초: 집단 기억이나 위기 장면 + 첫 숫자. 다큐형은 결과 대신 위기, 해설형은 결과 숫자.
3. **20초마다 새 사실 하나**(반전·규모·자격).
4. **30초 안에 제목 단어를 한 번 회수**(제목을 보고 들어온 사람이 "맞게 왔다"고 느끼게).
5. 약속을 말로 한 번: "그날 ○○가 무엇이었는지", "진짜 싼지 직접 가격으로".
6. **질문으로 본론에 들어간다**: "누군지 아시겠죠?" "어느 쪽이 진짜일까요?"

팁: 오프닝은 본론을 다 만든 뒤 마지막에 만들면 가장 센 장면을 고르기 쉽다. 위 1~6을 오프닝 제작 체크리스트로 쓴다.

## 6. 본론 리듬 — 구간 길이와 재후킹
- 구간 길이(실측): 10분 이하 0.5~1분 · 10~30분 1.5~3분 · 긴 토크 4~10분. 10~20분 1인 내레이션이면 1~2분마다 전환.
- 전환 수단: 새 숫자 공개 · 새 인물·사례 · 장소/화면 이동 · 승부·퀴즈 · 반전 사실 · 위기 발생.
- 재후킹 문장(실제로 쓰인 문형): "또 한 가지 놀라운 점은" · "그런데 웬일인가요?" · "문제는 여기서" · "아니 잠깐, 그럼 ○○는?"(시청자 목소리 반문) · "여기서 진짜 숫자가 드러나는데" · "잠시 뒤에 보여 드릴게요".
- **반복 소품**: 한 물건·화면을 세 번 등장시켜 이야기를 묶는다(페덱 카우보이 모자). 1인 채널이면 첫 정산 화면, 첫 주문 메일, 같은 대시보드.
- **약속 심기 → 회수**: 중간에 인물이 한 약속("대구에 우승 반지")을 뒤에서 지키는 장면 — 댓글이 정확히 여기에 반응했다.
- 협찬은 본문 중간에 짧게 녹인다(39개 중 협찬 영상 모두). 시연 → 필요성 → 소개 순이 자연스럽다.

## 7. 결말
- 단일 질문의 답을 4절에서 정한 위치에서 준다. 답 뒤에는 오래 끌지 않는다.
- 끝맺음(39개 실제): 수미상관(처음 장면으로 돌아가 의미를 바꿈) · 판정 한 줄 · 열린 질문 · 다음 편 떡밥(1편은 결과 직전에서 끊기).
- 영상 안에서 구독·좋아요를 말로 요청한 영상은 39개 중 2개였다. 답 → 수미상관·판정 한 줄에서 끝내는 편이 많다. **[내 채널]** 엔딩 요청을 넣을지는 CHANNEL.md 규칙을 따른다.

```
- 공유될 한 줄(댓글에 옮겨질 숫자·말):
- 제목 후보 3(문형 번호):      · 썸네일 결과 장면 + 실제 한마디:
- 뼈대(A~E):  구간표(시간 | 역할 | 내용 | 전환 수단) 8~12행
- 오프닝 0~60초: 첫 문장 / 20초 사실 / 30초 제목 단어 회수 / 약속 / 질문

- 결말 방식:
- 검증: 모든 숫자 출처(✅ 원문 확인 / 🟡 2차 출처 / ❌ 미확인) · 썸네일 인용은 실제 발언인가
```
