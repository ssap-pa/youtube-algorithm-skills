# 채널 프로필

> 두 스킬(algorithm-topics, algorithm-analysis)이 매번 먼저 읽는 파일이다. 위치: 프로젝트의 `youtube-algorithm/CHANNEL.md`.
> 처음 실행 때 Claude가 이 양식으로 만들고 사용자에게 빈칸을 묻는다. 언제든 직접 고쳐도 된다. 여기 적은 규칙이 스킬의 패턴보다 우선한다.

## 채널
- 이름·주소: (예: 홍길동의 캠핑 · https://www.youtube.com/@handle)
- 채널 ID: (UC로 시작. 모르면 비워 두면 스킬이 핸들로 찾는다)
- 분야 한 줄: (예: 30~40대 직장인이 주말에 따라 할 수 있는 1박 캠핑 실측 후기)
- 영상 형식: (예: 1인 내레이션 + 실제 화면 / 얼굴 출연 토크 / 2인 대화 / 브이로그)
- 주 시청자: (나이·상황·왜 보는가)

## 다루는 주제 범위
- 다룬다: (예: 장비 실측 가격, 캠핑장 실제 후기, 유행 장비가 뜬/사라진 이유)
- 다루지 않는다: (예: 정치, 투자 권유, 확인 안 된 루머)

## 시청자가 반응한 축 (채널 적합도 채점 기준)
> 스킬이 내 채널 영상의 조회·구독 증가 상위 5개를 보고 채운다. 사용자가 고쳐도 된다.
- ① (예: 시청자가 직접 따라 해 보는 것)
- ② (예: 불안 해소 — 손해·실패를 피하는 법)
- ③ (예: 실제 숫자가 있는 사례)
- 기준 영상: (제목 · 조회 · 구독 증가)

## 지키는 규칙 (스킬 패턴보다 우선)
- (예: 제목에 결과·답을 넣지 않는다 — 궁금하게)
- (예: 숫자·인용은 원문으로 확인한 것만, 썸네일 따옴표는 실제 발언만)
- (예: 엔딩에 좋아요·구독 요청을 넣지 않는다)
- (예: 화제·뉴스는 최근 24시간 보도만 '오늘 화제'로 쓴다)
- (예: 제목·썸네일은 사람이 최종 확정)
